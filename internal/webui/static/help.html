Генератор Мой почерк Справка

Как это устроено

Настоящий почерк с листа: каждая буква в нескольких исполнениях, затем сборка нового текста.

Три слоя

1
Спрайты букв. Фото выравнивается по перспективе и свету, линовка и клетки распознаются, каждая буква вырезается в маску. Повторы одной буквы становятся разными вариантами.
2
Раскладка. Текст разбивается на строки по ширине колонки. Каждая буква получает свой поворот, наклон, размер, нажим и сдвиг по базовой линии.
3
Бумага и съёмка. Тетрадный фон, красное поле, старение; затем физика чернил и имитация съёмки: сканер, телефон, факс.

Как написать образец

  • Распечатайте шаблон в масштабе 100 %, без «по размеру страницы».
  • Пишите той ручкой, которой обычно пишете: важна ваша манера, а не каллиграфия.
  • По одной букве в клетку, не выходя далеко за рамки.
  • Не старайтесь писать красиво. Нужен обычный почерк вместе с его неровностями.
  • Заполняйте все повторы — разные варианты одной буквы делают письмо живым.
  • Если буква не получилась — зачеркните клетку и напишите рядом, а при разметке уберите лишнюю ячейку.

Как сфотографировать

  • Сверху, параллельно листу. Под углом перспектива исправляется, но теряется резкость.
  • Свет ровный, без вспышки и резкой тени от телефона. Дневная лампа сбоку — лучший вариант.
  • Лист занимает почти весь кадр, края видны целиком.
  • Коснитесь экрана, чтобы сфокусироваться на тексте. Размытые буквы не вырежутся.
  • Скан с принтера тоже подходит — даже лучше.

Подбор шрифта

В панели «Почерк» откройте «Браузер шрифтов». Каждая карточка показывает настоящий шрифт: введите своё имя или фразу в поле «Образец», чтобы сравнить начертания. Фильтр «Кириллица» оставляет только шрифты с русскими буквами. Выберите карточку и нажмите «Создать профиль».

API для агентов /api/v1

Всё, что делает интерфейс, доступно по HTTP. Ответы — JSON, изображения — PNG, плюс готовые PDF и ZIP.

Сгенерировать страницу

curl -sS http://127.0.0.1:8080/api/v1/generate \
  -H 'content-type: application/json' \
  -d '{
    "text": "Сочинение по литературе.\n\nПрирода в романе — не фон, а действующее лицо…",
    "profileId": "p_8f31c2",
    "seed": 20250517,
    "page":   { "width": 1240, "height": 1754, "columns": 1, "indent": 2, "align": "justify" },
    "paper":  { "kind": "lined", "cellMm": 8, "marginMm": 20, "aging": 0.15 },
    "pen":    { "kind": "ballpoint", "color": "#141a3a", "pressure": 0.55 },
    "style":  { "variability": 1, "join": 0.6 },
    "flaws":  { "crossOut": 0.02, "correction": 0.03, "blot": 0.2, "stain": 0.05 },
    "effects":{ "kind": "phone", "jpeg": 82, "vignette": 0.3 }
  }'
# → {"id":"r_1a2b3c","pages":["/api/v1/results/r_1a2b3c/page-001.png"],"millis":840}

curl -sS -o page.pdf http://127.0.0.1:8080/api/v1/results/r_1a2b3c/export.pdf
curl -sS -o pages.zip http://127.0.0.1:8080/api/v1/results/r_1a2b3c/export.zip

Длинные тексты лучше отправлять асинхронно: добавьте "async": true, получите jobId и опрашивайте GET /api/v1/jobs/{jobId}.

Свой почерк без браузера

# 1. Шаблон: список листов и их спецификаций
curl -sS 'http://127.0.0.1:8080/api/v1/template?lang=ru&reps=2'

# 2. Фото заполненного листа → нормализованный скан + ячейки
curl -sS http://127.0.0.1:8080/api/v1/capture \
  -F 'file=@sheet.jpg' \
  -F 'spec={"lang":"ru","reps":2,"page":0,"pages":2,"chars":["а","б"]}'

# 3. Поправить разметку (полная замена набора ячеек)
curl -sS -X POST http://127.0.0.1:8080/api/v1/capture/c_77/cells \
  -H 'content-type: application/json' \
  -d '{"cells":[{"id":1,"rect":[120,340,300,520],"label":"а"}]}'

# 4. Собрать профиль
curl -sS -X POST http://127.0.0.1:8080/api/v1/capture/c_77/commit \
  -H 'content-type: application/json' \
  -d '{"name":"Мой почерк","assignments":[],"style":{}}'

Вопросы

Почему буквы иногда «пляшут»?

Так работает разброс: у каждой буквы свой поворот и сдвиг, у строки — собственное дрожание. Уменьшите «Разброс» в группе «Стиль письма», если нужно ровнее.

Чем «телефон» отличается от «сканера»?

«Сканер» выбеливает бумагу, добавляет пыль и полосы. «Телефон» наклоняет лист, добавляет перспективу, виньетку, тень и артефакты JPEG.

Можно ли смешать два почерка?

Возьмите лист с буквами, которые хотите взять из другого почерка, и создайте профиль только с ними. Пока профиль один на страницу.

Где хранятся данные?

Всё локально: data/profiles — почерки, data/captures — сканы и разметка, data/results — готовые страницы. Внешних сервисов нет.
